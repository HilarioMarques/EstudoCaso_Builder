# Projeto - Builder de Relatórios em Java

## Requisitos

- Java JDK 21 (ou superior)
- Terminal (Prompt de Comando, PowerShell ou Terminal do VS Code)

## Como executar

### 1. Abrir a pasta do projeto

Abra a pasta onde estão todos os arquivos `.java`.

### 2. Compilar o projeto

No terminal, execute:

```bash
javac *.java
```

Se a compilação ocorrer corretamente, serão gerados os arquivos `.class`.

### 3. Executar o programa

Após a compilação, execute:

```bash
java Main
```

A saída será exibida no terminal.

## Estrutura

Cada classe está em seu próprio arquivo `.java` e utiliza o pacote padrão (sem declaração de package).

## Observações

- O projeto foi desenvolvido e testado utilizando Java 21.
- Também pode ser executado diretamente pelo Visual Studio Code com a extensão **Extension Pack for Java** instalada.
- Caso ocorra erro informando que os comandos `java` ou `javac` não foram encontrados, verifique se o JDK está instalado e configurado corretamente no sistema.
